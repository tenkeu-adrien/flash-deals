- Si statut = rejected → Message + Blocage

BOUTON "DEVENIR PARTENAIRE":
---------------------------
- Adapte son texte selon le statut
- Désactivé si pending ou rejected

CONNEXION ADMIN:
---------------
- Vérifie dans Firestore collection "admins"
- Si pas admin → Message clair + Déconnexion
- Si admin → Accès autorisé

========================================
STRUCTURE FIRESTORE REQUISE
========================================

Collection "admins":
admins/{userId}
  - email: string
  - name: string
  - role: "admin" | "super_admin"
  - createdAt: timestamp

Pour créer un admin:
1. Créer utilisateur dans Authentication
2. Noter son UID
3. Créer document dans "admins" avec cet UID
4. Ajouter les champs requis
