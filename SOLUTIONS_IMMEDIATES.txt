🔴 PROBLÈME 1: Aucun deal ne s'affiche
───────────────────────────────────────────────────────────────
SOLUTION:
1. Ouvrir Firebase Console: https://console.firebase.google.com/project/wego-97624
2. Aller dans Firestore Database > campaigns
3. Vérifier qu'il y a des documents
4. Pour chaque campagne, vérifier que status = "active"
5. Si status = "pending", le changer en "active"

OU créer une campagne de test:
- Aller sur http://localhost:3000/vendeur
- S'inscrire comme vendeur
- Créer une campagne
- Dans Firestore, changer le status à "active"

═══════════════════════════════════════════════════════════════

🔴 PROBLÈME 2: Erreur "email-already-in-use"
───────────────────────────────────────────────────────────────
SOLUTION RAPIDE:
Utiliser un email différent pour le vendeur
Exemple: vendeur@test.com au lieu de client@test.com

OU

Supprimer l'utilisateur existant:
1. Firebase Console > Authentication
2. Trouver l'utilisateur
3. Cliquer sur les 3 points > Supprimer
4. Réessayer l'inscription

═══════════════════════════════════════════════════════════════

🔴 PROBLÈME 3: Clic sur deal ne fait rien
───────────────────────────────────────────────────────────────
SOLUTION:
1. Vérifier que vous êtes connecté
2. Ouvrir la console (F12) et chercher les erreurs
3. Redémarrer le serveur: npm run dev
4. Vider le cache du navigateur (Ctrl+Shift+Del)

═══════════════════════════════════════════════════════════════

🔴 PROBLÈME 4: Déconnecté après rechargement
───────────────────────────────────────────────────────────────
SOLUTION:
1. Vérifier que FirebaseProvider est dans app/layout.tsx
2. Redémarrer le serveur
3. Se reconnecter
4. Vérifier dans la console: "✅ Utilisateur connecté"

📞 DEBUG
───────────────────────────────────────────────────────────────
1. Ouvrir la console du navigateur (F12)
2. Chercher les messages:
   - "✅ X campagne(s) récupérée(s)" = OK
   - "⚠️ Aucune campagne active" = Vérifier Firestore
   - Erreurs en rouge = Copier le message complet

3. Vérifier Firebase Console:
   - Authentication > Users (doit avoir des utilisateurs)
   - Firestore > campaigns (doit avoir des documents)
   - Storage (doit être activé)
